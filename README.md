# Data Warehouse and Analytics Project

## Overview

This project demonstrates the design and implementation of a modern data warehouse using Microsoft SQL Server to consolidate sales data from ERP and CRM source systems into a centralized, analytics-ready environment.

The solution covers data ingestion, data quality, data integration, data modeling, and SQL-based analytics, providing a foundation for reliable reporting and data-driven decision-making.

## Project Objectives

### Data Engineering: Building the Data Warehouse

Develop a centralized data warehouse that integrates sales data from multiple source systems into a consistent and structured data model.

Key activities include:

- **Data Ingestion:** Load sales data from ERP and CRM source systems provided as CSV files.
- **Data Quality:** Identify and resolve data inconsistencies, missing values, and other data quality issues.
- **Data Integration:** Combine data from multiple sources into a unified analytical model.
- **Data Modeling:** Structure data to support efficient analytical queries and reporting.
- **Data Scope:** Focus on the latest available dataset without implementing historical data tracking.

### Data Analytics: SQL-Based Reporting

Leverage SQL to analyze sales data and generate actionable business insights across three key areas:

- **Customer Behavior:** Analyze customer purchasing patterns and behavior.
- **Product Performance:** Evaluate product performance and contribution to sales.
- **Sales Trends:** Examine sales performance and identify relevant trends.

## Technology Stack

- **Database:** Microsoft SQL Server
- **Query Language:** SQL
- **Data Sources:** ERP and CRM datasets in CSV format
- **Version Control:** Git and GitHub
